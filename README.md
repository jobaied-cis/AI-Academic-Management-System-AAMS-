# 🎓 AI Academic Management System (AAMS)

A full-stack web application built to manage academic activities efficiently for students, teachers, and administrators.

---

## 🚀 Overview

AI Academic Management System (AAMS) is designed to simplify academic workflows such as managing student data, teacher interactions, and academic records. This project demonstrates full-stack development using modern technologies.

---

## ✨ Features

- 👨‍🎓 Student Profile Management  
- 🧑‍🏫 Teacher Dashboard  
- 📊 Academic Data Handling  
- 🔐 Authentication System (Login/Signup)  
- 🔄 REST API Integration  
- 🌐 Responsive UI  

---

## 🛠️ Tech Stack

### 🔹 Frontend
- React.js  
- Tailwind CSS  
- Vite  

### 🔹 Backend
- Java (Spring Boot)  
- REST API  

### 🔹 Tools & Platforms
- Git & GitHub  
- VS Code  
- Maven

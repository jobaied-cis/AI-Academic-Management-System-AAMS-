# AAMS - AI Academic Management System

> A modern, professional React.js frontend for university academic management.

## Project Structure

```text

|-- public/
|-- src/
|   |-- main.jsx
|   |-- App.jsx

|   |-- context/
|   |-- data/

|   `-- pages/
|-- backend/
|-- index.html
|-- package.json
|-- vite.config.js
|-- tailwind.config.js
`-- postcss.config.js
```

## Getting Started

1. Install Node.js 18+.
2. Run `npm install`.
3. Start the frontend with `npm run dev`.
4. Open `http://localhost:5173`.
